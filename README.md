# Issue Tracker

A full-stack issue tracking application to manage tasks, bugs, and project progress efficiently. Built using Next.js, TypeScript, and Prisma ORM, this project demonstrates modern web development skills with a focus on clean architecture and usability.

## Features
- Create, update, and delete issues
- Assign issues to team members
- Track issue status and priority
- Responsive UI for web and mobile
- Secure backend using Prisma and database integration

## Technologies
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Next.js API routes, Prisma ORM
- Database: mysql
- Deployment-ready with Vercel
